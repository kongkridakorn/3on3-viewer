# Beyblade Box Assembly (3D viewer)

Interactive 3D viewer and step-by-step assembly animation for the 3-bay Beyblade Box with push-bar latch, spring-gear pop-up lids and replaceable button pins.

Open `index.html` in a browser: orbit, explode, open the lids, and play the 11-step Assembly mode.
